## Встроенные функции

Zmey Gorynich включает несколько встроенных функций:

| Функция | Аргументы | Описание | Пример |
|---------|-----------|----------|--------|
| `молвить` | Произвольное количество | Выводит значения в консоль. | `молвить("Гойда!", 42) гойда` |
| `глас` | Значение | Выводит имя переменной, значение и тип в цвете. | `глас(ящер) гойда` |
| `внемли` | Имя переменной (или строка и имя) | Считывает ввод пользователя. | `внемли ящер быти цело гойда` |
| `созвать_дружину` | `размер`, `значение` | Создаёт список заданного размера с заполнением значением. | `массив = созвать_дружину(3, 0) гойда` |
| `имя_аргумента` | Контекст | Возвращает имя аргумента функции (для отладки). | |
| `тип_значения` | Значение, контекст | Возвращает тип значения. | |
| `строчить_значение` | Значение, контекст | Преобразует значение в строку. | |

**Пример работы `глас`**:
```zmeygorynich
ящер быти цело = 42 гойда
глас(ящер) гойда
```
Вывод:
```
ᚨᛇᛟ: ящер -> 42 быти цело
```
