## Режим отладки

Интерпретатор поддерживает режим отладки, который включается установкой переменной `DEBUG = True` в файле `interpreter.py`. В этом режиме перед выполнением программы выводятся:

1. **Токены**: Список токенов, полученных на этапе лексического анализа.
2. **AST**: Абстрактное синтаксическое дерево, построенное парсером.

Пример вывода при `DEBUG = True`:

```
Tokens: [('ID', 'ящер', 1, 1), ('TYPE_ANNOTATION', 'быти', 1, 7), ('ID', 'цело', 1, 12), ('ASSIGN', '=', 1, 17), ('число', '42', 1, 19), ('GOYDA', 'гойда', 1, 22)]

AST: [<node.Node type=Assignment, value=None, op=None, type_hint=число:int, children=[<node.Node type=ID, value=ящер>, <node.Node type=число, value=42>], line=1, col=1>]

Результат программы:
ящер -> 42 быти цело
```

При `DEBUG = False` выводится только результат выполнения программы:

```
Результат программы:
ящер -> 42 быти цело
```

Режим отладки полезен для разработчиков, анализирующих работу интерпретатора или отлаживающих сложные программы.
