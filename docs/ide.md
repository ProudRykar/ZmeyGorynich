# Обзор IDE ZmeyGorynich

Графическая IDE для языка программирования **ZmeyGorynich** (Русь-тематика,
кириллический синтаксис). Написана на Python + PyQt5, безрамочное окно с
кастомной тёмной «славянской» темой. Ядро языка (`src/zmeygorynich`) подключается
через `sys.path` и не модифицируется — IDE использует его tokenizer/parser/
evaluator напрямую.

## Технологии

- **Python 3** + **PyQt5** (виджеты, QSS-тема, многопоточность).
- **QScintilla** (`PyQt5.Qsci`) — редактор с подсветкой, автодополнением,
  маркерами/индикаторами ошибок, hover-подсказками.
- Ядро языка подключается через `ide/lang_core.py` (плоские импорты из
  `src/zmeygorynich`).

## Запуск

```
pip install -r requirements-ide.txt
./run_ide.sh            # или: python -m ide.main
```

## Архитектура (карта файлов `ide/`)

| Файл | Назначение |
|------|------------|
| `main.py` | Точка входа: `QApplication` → `apply_theme` → `MainWindow`. |
| `main_window.py` | `MainWindow` (всё окно) и `TitleBar` (кастомная шапка с лого, меню «Файл», кнопкой «Справочник» и кнопками окна). Компоновка через `QSplitter`. |
| `theme.py` | Тёмная палитра, QSS-таблица стилей, загрузка кастомных шрифтов (Balkara, SPSL), `apply_theme()`. |
| `sidebar.py` | Боковая панель в стиле VS Code: активити-бар (значки) + сменяемые панели «Проводник» (дерево файлов) и «Символы» (функции/переменные). |
| `reference.py` | Диалог-справочник языка (HTML-описание типов, операторов, встроенных функций, управления потоком, импорта). |
| `terminal_view.py` | Эмуляция терминала: вывод программы + интерактивный ввод (`внемли`) в ту же область. |
| `editor/zg_editor.py` | Класс `ZGEditor` (наследник `QsciScintilla`): диагностика (волнистые линии), автодополнение, hover, call-tips, сниппеты. |
| `editor/scintilla_lexer.py` | Толерантный regex-лексер подсветки (не зависит от строгого `tokenize`, работает на недописанном коде). |
| `analysis/analyzer.py` | Статический анализ: сбор диагностик (ошибки синтаксиса, повтор функции, число аргументов вызова) и таблицы символов. |
| `analysis/symbols.py` | Модель символов (`Symbol`, `SymbolTable`). |
| `analysis/completions.py` | Ключевые слова, типы, встроенные функции, сниппеты, построение списка для `QsciAPIs`. |
| `analysis/hover.py` | Формирование текста hover/call-tip по имени идентификатора. |
| `run/runner.py` | `Runner` (наследник `QThread`): выполняет `.zg`-код в отдельном потоке, перехватывает stdout/stderr/ввод и стримит в GUI. |
| `lang_core.py` | Адаптер к ядру языка. |

## Реализованные возможности

- **Редактор**: подсветка синтаксиса, нумерация строк, отступы, автодополнение
  (ключевые слова/функции/переменные/типы), сниппеты, call-tips по сигнатурам,
  hover-подсказки, подчёркивание ошибок волнистой линией.
- **Анализ «на лету»** (с дебаунсом 300 мс): диагностика и обновление дерева
  символов/автодополнения при каждом изменении текста.
- **Боковая панель**: проводник файлов (ленивая подгрузка каталогов, фильтр
  `.zg`/`.py`) и панель символов (переход к определению по двойному клику).
- **Запуск кода**: в отдельном потоке, с живым выводом и интерактивным вводом
  прямо в терминале снизу. Вкладки «Проблемы» / «Вывод».
- **Справочник языка**: отдельный диалог с категориями.
- **Кастомная шапка**: лого, меню «Файл» (Новый/Открыть/Сохранить/Выход),
  кнопка «Справочник», кнопки управления окном, перетаскивание окна за шапку.
- **Тема**: тёмная палитра, кастомные шрифты, скруглённые панели, кастомные
  скроллбары, фоновое изображение дракона в панелях вывода, золотой акцент.
- **Поиск и замена**: панель поверх редактора (Ctrl+F — найти, Ctrl+H — найти и
  заменить) в правом верхнем углу; навигация Enter/Shift+Enter, учёт регистра,
  только целые слова, регулярные выражения, замена одного/всех вхождений.

## Текущие ограничения

- Нет отладчика (точки останова, пошаговое выполнение, просмотр стека).
- Нет поиска/замены по нескольким файлам (только в текущем редакторе).
- Проводник не поддерживает переименование/создание/удаление файлов.
- Нет настроек (шрифт редактора, тема, горячие клавиши).
- Анализ поверхностный: нет семантической проверки типов в IDE (есть только
  базовые предупреждения), нет перехода к определению символа в редакторе
  (только в боковой панели), нет rename-рефакторинга.
- Один язык/раскладка; нет мульти-курсора, форматирования кода, сворачивания
  блоков (folding отключён).
- Справочник — статичный словарь, не генерируется из ядра.

## Что можно добавить (идеи)

1. **Поиск и замена** — панель поиска в редакторе уже реализована (Ctrl+F /
   Ctrl+H). Осталось добавить поиск по проекту через проводник.
2. **Отладчик** — интеграция с трассировкой ядра: точки останова в полях
   редактора, пошаг, инспектор переменных (вывод из `Context`).
3. **Дерево структуры файла** с переходом и **«перейти к определению»** по
   Ctrl+Click в редакторе (использовать `SymbolTable` + `setCursorPosition`).
4. **Форматирование/автоотступы** по грамматике языка и **сворачивание блоков**
   (`setFolding` по `ухожу я в пляс`/`закончили пляски`).
5. **Действия с файлами** в проводнике: создать/переименовать/удалить, контекстное
   меню, drag-and-drop открытия.
6. **Настройки IDE** (диалог): шрифт/размер редактора, переключение темы,
   горячие клавиши; сохранение в `QSettings`.
7. **Горячие клавиши**: сохранить (Ctrl+S), запустить (Ctrl+R/Shift+Enter),
   закрыть вкладку, переключение боковой панели (Ctrl+B).
8. **Вкладки с состоянием** и восстановление последней сессии при старте.
9. **Справочник, генерируемый из ядра** (встроенные функции/типы из
   `zg_builtins`/`TYPE_MAP`), чтобы не дублировать вручную.
10. **LSP-подобный слой** на базе существующего анализа: диагностика в реальном
    времени уже есть — добавить семантику (типы из `typecheck`), быстрые
    исправления, подсказки по аргументам функций.
11. **Терминал для произвольных команд** (не только вывод программы) и
    перенаправление `exit code` в статус-бар.
12. **Мультиязычность/локализация** UI (сейчас всё на русском, что логично для
    языка, но можно сделать переключатель).
