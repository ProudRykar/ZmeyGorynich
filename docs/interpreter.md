## Интерпретатор

Интерпретатор (`interpreter.py`) выполняет код, обрабатывая AST в контексте, который хранит переменные, функции и их типы.

**Ключевые компоненты**:
- **Context**: Класс для управления переменными, функциями и типами. Поддерживает вложенные контексты для функций.
- **evaluate**: Функция для выполнения узлов AST.
- **check_type**: Проверка соответствия типов при присваивании.
- **call_function**: Вызов пользовательских и встроенных функций.

**Этапы выполнения**:
1. Чтение файла `.zg`.
2. Токенизация с помощью `tokenize`.
3. Построение AST с помощью `parse`.
4. Выполнение AST с помощью `evaluate`.
