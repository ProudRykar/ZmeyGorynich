## Лексический анализ и парсинг

### Лексический анализ (`lexer.py`)

Модуль `lexer.py` отвечает за токенизацию исходного кода. Он преобразует код в последовательность токенов, используя регулярные выражения.

**Основные токены**:
- `число`: Числа (целые и с плавающей точкой).
- `ID`: Идентификаторы (имена переменных, функций, включая руны).
- `строченька`: Строки в кавычках.
- `GOYDA`: Разделитель команд (`гойда`).
- `OP`: Операторы (`+`, `-`, `*`, `/`, `%`, `**`, `<`, `>`, `==`, etc.).
- `TYPE_ANNOTATION`: Ключевое слово `быти` для типизации.
- `BRACKET`: Квадратные скобки для списков (`[`, `]`).
- `PARENTHESIS`: Круглые скобки для функций и выражений (`(`, `)`).

**Пример токенов**:
```zmeygorynich
ящер = 42 гойда
```
Токены:
```
[('ID', 'ящер', 1, 1), ('ASSIGN', '=', 1, 7), ('число', '42', 1, 9), ('GOYDA', 'гойда', 1, 12)]
```

### Парсинг (`parser.py`)

Модуль `parser.py` преобразует токены в абстрактное синтаксическое дерево (AST). Он поддерживает рекурсивный спуск для обработки выражений, условий, циклов, функций и других конструкций.

**Основные узлы AST**:
- `Assignment`: Присваивание переменной.
- `ArrayAssignment`: Присваивание элементу списка.
- `Print`: Вывод (`молвить`).
- `Input`: Ввод (`внемли`).
- `If`: Условный оператор.
- `While`: Цикл `покуда`.
- `FixedLoop`: Фиксированный цикл.
- `Function`: Объявление функции.
- `Call`: Вызов функции.
- `Import`: Импорт файла.

**Пример AST**:
```zmeygorynich
ящер = 42 гойда
```
AST:
```
[<node.Node type=Assignment, value=None, op=None, type_hint=None, children=[<node.Node type=ID, value=ящер>, <node.Node type=число, value=42>], line=1, col=1>]
```
