## Синтаксис языка

### Ключевые слова и структура

- **Разделитель команд**: Каждая команда вне блока кода завершается словом `гойда`.
- **Блоки кода**: Определяются конструкциями `ухожу я в пляс` (начало блока) и `закончили пляски` (конец блока).
- **Комментарии**:
  - Однострочные: начинаются с `#`.
  - Многострочные: начинаются с `Голос предков шепчет:` и заканчиваются `Голос предков внезапно стих...`.

Пример:

```zmeygorynich
# Это однострочный комментарий
Голос предков шепчет:
  Это многострочный комментарий
  Можно писать несколько строк
Голос предков внезапно стих...

ящер = 42 гойда
ухожу я в пляс
  молвить(ящер) гойда
закончили пляски
```

### Типы данных

Zmey Gorynich поддерживает следующие типы данных:

| Тип в языке | Внутренний тип Python | Описание |
|-------------|-----------------------|----------|
| `цело`      | `int`                 | Целое число. |
| `плывун`    | `float`               | Число с плавающей точкой (двойная точность). |
| `плывун малый точный` | `decimal.Decimal` (prec=30) | Число с точностью 30 знаков. |
| `плывун великий` | `decimal.Decimal` (prec=50) | Число с точностью 50 знаков. |
| `плывун звёздный` | `decimal.Decimal` (prec=100) | Число с точностью 100 знаков. |
| `строченька` | `str`                | Строка. |
| `двосуть`   | `bool`                | Булево значение (`истина` или `ложь`). |
| `список`    | `list`                | Список, может быть типизирован (например, `список цело`). |

Типы указываются с помощью ключевого слова `быти` при объявлении переменных.

### Объявление переменных

Переменные могут объявляться с явной типизацией или без неё (динамическая типизация).

**Синтаксис**:
```zmeygorynich
имя_переменной быти тип = выражение гойда
имя_переменной = выражение гойда
```

**Примеры**:
```zmeygorynich
ящер быти цело = 42 гойда              # Целое число
змейка быти плывун = 3.14 гойда        # Число с плавающей точкой
имя быти строченька = "Гойда!" гойда   # Строка
флаг быти двосуть = истина гойда       # Булево значение
массив быти список цело = [1, 2, 3] гойда  # Список целых чисел
точность быти плывун малый точный = 1.123456789012345678901234567890 гойда
```

Без явного указания типа:
```zmeygorynich
ящер = 100 + 9 гойда  # Автоматически цело (109)
```

**Особенности**:
- При использовании типов `плывун малый точный`, `плывун великий`, `плывун звёздный` значения автоматически преобразуются в `decimal.Decimal` с заданной точностью.
- Типизация проверяется во время выполнения, и при несоответствии типа выбрасывается ошибка.

### Арифметические операции

Поддерживаемые операции:
- `+` — сложение.
- `-` — вычитание.
- `*` — умножение.
- `/` — деление.
- `%` — остаток от деления.
- `**` — возведение в степень.
- `корешок из` — квадратный корень.

**Примеры**:
```zmeygorynich
ящер = 10 + 5 гойда    # 15
ящер = 10 - 3 гойда    # 7
ящер = 10 * 2 гойда    # 20
ящер = 10 / 2 гойда    # 5.0
ящер = 10 % 3 гойда    # 1
ящер = 2 ** 3 гойда    # 8
ящер = корешок из 16 гойда  # 4
```

**Особенности**:
- Операции с числами высокой точности (`плывун малый точный`, `плывун великий`, `плывун звёздный`) используют `decimal.Decimal`.
- Операция `+` поддерживает конкатенацию строк и списков.

### Работа со строками

- **Конкатенация**: Выполняется с помощью оператора `+`.
- **Вывод**: Используется функция `молвить` для вывода строк.

**Пример**:
```zmeygorynich
текст = "ящер" + " гойда" гойда  # "ящер гойда"
молвить(текст) гойда
```

### Списки

Списки в Zmey Gorynich поддерживают создание, доступ по индексу, присваивание и конкатенацию.

**Синтаксис**:
- Создание: `имя = [элемент1, элемент2, ...] гойда`.
- Создание с заполнением: `созвать_дружину(длина, значение)`.
- Доступ: `имя[индекс]`.
- Присваивание: `имя[индекс] = значение гойда`.
- Конкатенация: `список1 + список2`.

**Примеры**:
```zmeygorynich
массив = [1, 2, 3] гойда
массив = созвать_дружину(3, 0) гойда  # [0, 0, 0]
массив[1] = 42 гойда                  # [0, 42, 0]
молвить(массив[1]) гойда              # 42
массив2 = [4, 5, 6] гойда
массив3 = массив + массив2 гойда      # [0, 42, 0, 4, 5, 6]
```

**Особенности**:
- Индексы начинаются с 0.
- При доступе к несуществующему индексу или некорректному типу выбрасывается ошибка.

### Условные операторы

Поддерживаются конструкции `аще` (if), `аще ли` (elif), `ино` (else).

**Синтаксис**:
```zmeygorynich
аще условие то ухожу я в пляс
  команды
закончили пляски

аще ли условие то ухожу я в пляс
  команды
закончили пляски

ино ухожу я в пляс
  команды
закончили пляски
```

**Операторы сравнения**:
- `==` — равно.
- `!=` — не равно.
- `>` — больше.
- `<` — меньше.
- `>=` — больше или равно.
- `<=` — меньше или равно.
- `===` — строгое равенство (аналог `==`).

**Пример**:
```zmeygorynich
ящер быти цело = 10 гойда
аще ящер == 10 то ухожу я в пляс
  молвить("Ящер ровно 10!") гойда
закончили пляски
аще ли ящер > 5 то ухожу я в пляс
  молвить("Ящер велик!") гойда
закончили пляски
ино ухожу я в пляс
  молвить("Ящер мал!") гойда
закончили пляски
```

### Циклы

#### Цикл `покуда` (while)

Выполняет блок кода, пока условие истинно.

**Синтаксис**:
```zmeygorynich
покуда условие ухожу я в пляс
  команды
закончили пляски
```

**Пример**:
```zmeygorynich
ящер = 0 гойда
покуда ящер < 5 ухожу я в пляс
  ящер = ящер + 1 гойда
  молвить(ящер) гойда
закончили пляски
```

#### Фиксированные циклы

Поддерживаются циклы с заранее заданным числом итераций.

**Ключевые слова**:
- `дважды` — 2 раза.
- `трижды` — 3 раза.
- `четырежды` — 4 раза.
- `пятьжды` — 5 раз.
- `шестьжды` — 6 раз.
- `семьжды` — 7 раз.
- `осьмьжды` — 8 раз.
- `девятьжды` — 9 раз.
- `десятьжды` — 10 раз.
- `стожды` — 100 раз.

**Синтаксис**:
```zmeygorynich
# С блоком кода
ключ_цикла ухожу я в пляс
  команды
закончили пляски

# С одиночной командой
ключ_цикла команда гойда
```

**Пример**:
```zmeygorynich
# С блоком
ᚢ быти цело = 0 гойда
десятьжды ухожу я в пляс
  ᚢ = ᚢ + 1 гойда
  молвить(ᚢ) гойда
закончили пляски

# С одиночной командой
пятьжды молвить("Гойда!") гойда
```

### Функции

Функции объявляются с помощью ключевого слова `сотвори` и возвращают значение с помощью `возверни`.

**Синтаксис**:
```zmeygorynich
сотвори имя(параметры) изречет тип_возврата ухожу я в пляс
  команды
  возверни значение
закончили пляски
```

**Пример**:
```zmeygorynich
сотвори факториал(n) изречет цело ухожу я в пляс
  результат = 1 гойда
  покуда n > 1 ухожу я в пляс
    результат = результат * n гойда
    n = n - 1 гойда
  закончили пляски
  возверни результат
закончили пляски

результат = факториал(5) гойда  # 120
молвить(результат) гойда
```

**Особенности**:
- Параметры могут быть типизированы с помощью `быти`.
- Возвращаемый тип указывается через `изречет` и должен быть одним из: `цело`, `плывун`, `строченька`, `двосуть`.

### Импорт файлов

Импорт файлов осуществляется с помощью конструкции `прочесть книгу`.

**Синтаксис**:
```zmeygorynich
прочесть книгу "имя_файла.zg" гойда
прочесть книгу "имя_файла.zg" и осмыслить слова как псевдоним гойда
```

**Пример**:
```zmeygorynich
прочесть книгу "Функции.zg" гойда
результат = факториал(5) гойда  # Использует функцию из файла Функции.zg
молвить(результат) гойда
```

**Особенности**:
- Импортированные переменные и функции становятся доступны в текущем контексте.
- Если указан псевдоним, переменные импортированного файла доступны через него (например, `псевдоним.переменная`).

### Поддержка рун

Язык поддерживает использование рунических символов (Unicode U+16A0–U+16FF) в именах переменных и строках.

**Пример**:
```zmeygorynich
ᚠ быти цело = 42 гойда
молвить(ᚠ) гойда  # Выведет: 42
молвить("ᚠᚢᚦᚨᛚᛏ") гойда  # Выведет строку с рунами
```
