## Обработка ошибок

Интерпретатор перехватывает ошибки, связанные с синтаксисом, типами данных, отсутствием переменных и другими проблемами, и выводит их в понятной форме. Python-ский стек вызовов (`Traceback`) скрывается, чтобы не перегружать пользователя лишней информацией.

Пример сообщения об ошибке:

```
Ошибка: Переменная 'неизвестная' не определена (строка 5, столбец 10)
```

Сообщения об ошибках включают:
- Тип ошибки (например, синтаксическая, ошибка типов, файл не найден).
- Номер строки и столбца, где произошла ошибка.
- Контекст ошибки с выделением проблемной строки и указателем на место ошибки.

Пример контекста ошибки:

```
  4 | ящер = 42 гойда
  5 | молвить(неизвестная) гойда
      |          →
Ошибка: Переменная 'неизвестная' не определена (строка 5, столбец 10)
```
