### Обновленная документация языка Zmey Gorynich

Текущая версия языка на основе примера от 14 апреля 2025 года. Документация обновлена с учетом добавления поддержки фиксированных циклов, улучшений в обработке типов, цветного вывода, отладочного режима и обработки ошибок.

---

## Запуск программы
Программа запускается командой:
```plaintext
python -m logic/interpreter.py examples/program.zg
```

### Режим отладки
Интерпретатор поддерживает режим отладки, который управляется переменной `DEBUG` в файле `interpreter.py`. Если `DEBUG = True`, интерпретатор выводит токены и AST перед выполнением программы. Если `DEBUG = False`, выводятся только результаты выполнения программы.

Пример вывода с `DEBUG = True`:
```
Tokens: [('ID', 'ящер', 1, 1), ...]

AST: [<node.Node type=Assignment, value=None, ...]

Результат программы:
ящер -> 42 быти цело
```

Пример вывода с `DEBUG = False`:
```
Результат программы:
ящер -> 42 быти цело
```

### Обработка ошибок
Интерпретатор перехватывает ошибки языка Zmey Gorynich (например, синтаксические ошибки, ошибки типов, отсутствующие переменные) и выводит только их сообщения, без Python-ского `Traceback`. Пример:

```
Ошибка: Переменная 'неизвестная' не определена (строка 5, столбец 10)
```

## Основные особенности
- Каждая команда вне блока кода заканчивается словом `гойда`.
- Блоки кода выделяются конструкциями `ухожу я в пляс` и `закончили пляски`.
- Поддерживаются базовые типы данных, операции, списки, условные операторы, циклы, функции и импорт файлов.
- Добавлена поддержка фиксированных циклов (`дважды`, `трижды` и т.д.).
- Поддерживается цветной вывод через функцию `глас` (из `Отладка.zg`) с использованием библиотеки `colorama`.

## Базовые команды и функции

### Вывод данных
- `молвить(значение)` — выводит значение в консоль.  
  Может принимать несколько аргументов через запятую или одиночные значения (строки, числа, переменные, выражения).

Примеры:
```zmeygorynich
молвить("Славянский зажим яйцами") гойда  # Выводит строку
молвить(5 + 9) гойда                     # Выводит 14
молвить("Число: ", число) гойда          # Выводит "Число: " и значение переменной число
молвить(ящер) гойда                      # Выводит значение переменной ящер
```

#### Цветной вывод с помощью функции `глас`
Функция `глас` используется для отладочного вывода с цветами:
- Имя переменной — зелёный цвет.
- Значение — синий цвет.
- Тип — жёлтый цвет.

Пример:
```zmeygorynich
прочесть книгу "Переменные.zg" гойда  # Там уже была определена переменная: ящер быти цело = 42
глас(ящер) гойда  # Выводит: ящер -> 42 быти цело
```

Пример вывода:
```
ящер -> 42 быти цело
ХЗ -> Истина быти двосуть
```

### Ввод данных
- `внемли переменная` — считывает ввод пользователя и присваивает его переменной. Поддерживает типизацию.

Пример:
```zmeygorynich
внемли ящер быти цело гойда
молвить(ящер) гойда  # Выводит введённое число
```

### Объявление переменных
Переменные могут объявляться с указанием типа через `быти` или без явного указания типа (динамическая типизация). Поддерживаемые типы:
- `быти цело` — целое число.
- `быти плывун` — число с плавающей точкой (двойная точность по умолчанию).
- `быти строченька` — строка.
- `быти двосуть` — булевое значение (`истина` или `ложь`).
- `быти список` — список (может быть типизирован, например, `список цело`).
- Специальные типы чисел с повышенной точностью:
  - `быти плывун малый точный` — число с точностью 30 знаков.
  - `быти плывун великий` — число с точностью 50 знаков.
  - `быти плывун звёздный` — число с точностью 100 знаков.

Примеры:
```zmeygorynich
ящер быти цело = 5 гойда
ящер быти плывун = 5.5 гойда
ящер быти строченька = "5" гойда
ящер быти двосуть = истина гойда
массив быти список строченька = ["первая", "вторая"] гойда
мера быти плывун малый точный = 1.123456789012345678901234567890 гойда
круг быти плывун великий = 3.141592653589793238462643383279502884197 гойда
звѣзды быти плывун звёздный = 1.618033988749894848204586834365638117720309179805762862135 гойда
```

Без явного указания типа:
```zmeygorynich
ящер = 100 + 9 гойда  # ящер будет целым числом (109)
```

## Арифметические операции
Поддерживаются следующие операции:
- `+` — сложение.
- `-` — вычитание.
- `*` — умножение.
- `/` — деление.
- `%` — остаток от деления.
- `**` — возведение в степень.
- `корешок из` — квадратный корень.

Примеры:
```zmeygorynich
ящер = 100 + 9 гойда    # 109
ящер = 100 - 9 гойда    # 91
ящер = 100 * 9 гойда    # 900
ящер = 100 / 9 гойда    # 11.111...
ящер = 100 % 9 гойда    # 1
ящер = 100 ** 2 гойда   # 10000
ящер = (10 ** 10) / (корешок из 100) гойда  # 316227766.016...
```

## Строки
- Конкатенация строк выполняется через `+`.

Пример:
```zmeygorynich
ящер = "ящер" + "гойда" гойда  # "ящергойда"
```

## Списки
- Объявление списка: `имя = [элемент1, элемент2, ...] гойда`.
- Создание списка с заданным размером и значением: `созвать_дружину(длина, значение) гойда`.
- Доступ по индексу: `имя[индекс]`.
- Присваивание по индексу: `имя[индекс] = значение гойда`.
- Конкатенация списков: `+`.

Примеры:
```zmeygorynich
МатушкаЗемля = [1, 2, 3] гойда
массив = созвать_дружину(3, 0) гойда    # [0, 0, 0]
массив[1] = 42 гойда                    # [0, 42, 0]
молвить(массив[1]) гойда                # Выведет: 42
массив2 = [1, 2, 3] гойда               # [1, 2, 3]
массив3 = массив + массив2 гойда        # [0, 42, 0, 1, 2, 3]
молвить(массив3) гойда                  # Выведет: [0, 42, 0, 1, 2, 3]
```

## Условные операторы
- `аще условие то` — if.
- `аще ли условие то` — elif.
- `ино` — else.

Операторы сравнения:
- `==` — равно.
- `!=` — не равно.
- `>` — больше.
- `<` — меньше.
- `>=` — больше или равно.
- `<=` — меньше или равно.
- `===` — строгое равенство (аналог `==`).

Пример:
```zmeygorynich
ящер быти цело = 10 гойда

аще ящер == 10 то ухожу я в пляс
    молвить("Ящер ровно 10!") гойда
закончили пляски

аще ли ящер > 5 то ухожу я в пляс
    молвить("Ящер велик!") гойда
закончили пляски

ино ухожу я в пляс
    молвить("Ящер мал!") гойда
закончили пляски
```

## Циклы

### Цикл `покуда` (while)
- `покуда условие` — выполняет блок кода, пока условие истинно.

Пример:
```zmeygorynich
ящер = 0 гойда
рептилия = 1 гойда

покуда ящер < 10 ухожу я в пляс
    ящер = ящер + 1 гойда
    рептилия = рептилия * ящер гойда
    молвить("ящер: ", ящер) гойда
    молвить("рептилия: ", рептилия) гойда
закончили пляски
```

### Фиксированные циклы
Поддерживаются фиксированные циклы, которые выполняют блок кода или одиночный оператор заданное количество раз. Поддерживаемые ключевые слова:
- `дважды` — 2 раза.
- `трижды` — 3 раза.
- `четырежды` — 4 раза.
- `пятьжды` — 5 раз.
- `шестьжды` — 6 раз.
- `семьжды` — 7 раз.
- `осьмьжды` — 8 раз.
- `девятьжды` — 9 раз.
- `десятьжды` — 10 раз.
- `стожды` — 100 раз.

Фиксированный цикл может содержать:
- Блок кода (с `ухожу я в пляс` и `закончили пляски`).
- Одиночный оператор, за которым следует `гойда`.

Примеры:
```zmeygorynich
# Цикл с блоком кода
ᚢ быти цело = 0 гойда
десятьжды ухожу я в пляс
    ᚢ = ᚢ + 1 гойда
    молвить(ᚢ) гойда
закончили пляски  # Выведет числа от 1 до 10

# Цикл с одиночным оператором
пятьжды молвить("ᚢ") гойда  # Выведет "ᚢ" 5 раз
```

## Функции
- Объявление: `сотвори имя(параметры) изречет тип`.
- Возврат значения: `возверни значение`.

Примеры:
```zmeygorynich
сотвори факториал(n) изречет цело ухожу я в пляс
    результат = 1 гойда
    покуда n > 1 ухожу я в пляс
        результат = результат * n гойда
        n = n - 1 гойда
    закончили пляски
    возверни результат
закончили пляски

сотвори возвысь(основа, степень) изречет плывун ухожу я в пляс
    возверни основа ** степень
закончили пляски

результат = факториал(5) гойда  # 120
молвить(результат) гойда

результат = возвысь(2, 3) гойда  # 8.0
молвить(результат) гойда
```

## Импорт файлов
- Поддерживается импорт файлов с расширением `.zg` через `прочесть книгу "имя_файла.zg"`.
- Импортированные переменные и функции становятся доступны в текущем контексте.

Пример:
```zmeygorynich
прочесть книгу "Функции.zg" гойда
ящер = 42 гойда
факториал(ящер) гойда  # Использует функцию факториал из Функции.zg
```

## Поддержка Рун
Язык поддерживает руны в именах переменных и строках.

Примеры:
```zmeygorynich
молвить("ᚠᚢᚦᚨᛚᛏ") гойда  # Выведет строку с рунами
ᚠ быти плывун = 2.3 гойда
молвить(ᚠ) гойда  # Выведет 2.3
```
